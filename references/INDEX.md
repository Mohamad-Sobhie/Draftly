# Library index

The map of every source in the thesis library. Claude reads this first and keeps it up to date; the student never needs to edit it. `library.html` is generated from this file.

One entry per source, newest at the bottom. Format (the block below is a template and is ignored by the library page):

```
## <source-id>            (authorlastname-year-shortword, or org-year-shortword)
- Citation: <full reference in the configured style>
- Type: legislation | case | supervisory | report | article | book | book-chapter | news | dataset
- Jurisdiction/tags: UK, EU, international, theory, case-study, primary, maybe...
- About: 2-3 sentences
- Key concepts: ...
- Relevant for: <thesis sections, e.g. 3.1, 4.2> (pp./sections)
- Status: unread | skimmed | notes taken | cited in draft | not used
- Files: pdf/<file>, text/<source-id>/
```
