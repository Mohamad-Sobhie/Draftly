# 📖 Draftly: all commands

Type any of these, with or without `/draftly` in front. Plain sentences work too.

### Getting around
| Type | What happens |
|---|---|
| `/draftly help` | the short version |
| `/draftly help all` | this full list |
| `/draftly menu` | the 5 main options |
| `/draftly where am I?` | 📋 status: deadline, sources, drafts, gaps, next steps |
| `/draftly what should I do this week?` | 1–3 next steps for the time left |

### 🗂️ Outline (table of contents)
| Type | Example |
|---|---|
| `outline` | `/draftly outline`: two structures from your abstract, with word budgets and sources per section |
| `use A` / `use B` | saves your choice |
| `outline: [change]` | `/draftly outline: merge 2.1 and 2.2` · `add a section on Archegos to chapter 2` · `rename 3.2` |
| `outline` / `show my outline` | your saved outline as an editable board: change titles and budgets, move, add, remove, then **Copy changes** and paste them into the chat |
| `undo the last outline change` | brings back the previous version |

Nothing is saved until you say **go**, and every earlier version is kept.

### 💡 Brainstorm
| Type | Example |
|---|---|
| `brainstorm [topic]` | `/draftly brainstorm angles for chapter 3` |
| `brainstorm based on my abstract` | ideas grounded in your own abstract |
| `narrower research questions` | `/draftly give me 3 narrower versions of my question` |
| `save ideas [numbers]` | `/draftly save ideas 2, 5 and 9` |

### ⚖️ Discuss: the five perspectives
🟦 Practitioner · 🟥 Skeptic · 🟩 Economist · 🟨 Historian · 🟪 Academic

| Step | Type | Example |
|---|---|---|
| 1 | `discuss [question]` | `/draftly discuss whether the PRA should regulate LDI funds directly` |
| 2 | `map where they fight` | contradictions, strongest/weakest evidence, agreement, blind spots |
| 3 | `write the briefing` | supervisor summary, 5 findings ranked by reliability, one thing to change |
| 4 | `grade your work` | 1–10 confidence per finding, weakest claim, bias check |
| all | `discuss [question], all stages` | runs 1–4 in one go |

More: `debate the Skeptic and the Historian` · `play the examiner` · `go deeper on the Economist` · `what do you honestly think?` · `use schools of thought instead` · `save it as a page`

### ✍️ Write
| Type | Example |
|---|---|
| `draft [section]: [your points]` | `/draftly draft 3.1: banks see only their own exposure; 2022 showed…; my view is…` |
| `draft [section] using this discussion` | turns the last Discuss into prose |
| `polish this, keep my voice: [text]` | edits your own paragraph, says what changed |
| `make [section] shorter` | `/draftly cut chapter 2 by 500 words` |
| `fix the footnotes in [chapter]` | OSCOLA (or your style) clean-up |
| `can my library fill the gaps in [chapter]?` | matches [CITATION NEEDED] markers to your sources |

Before writing, you get a short **plan** to check: say **go**, change it, or say *just write it* to skip. Every draft is a new version (v1, v2…), never overwritten, and ends with **Notes for you** and a **style check**.

### 📚 Library
| Type | Example |
|---|---|
| *(drag a PDF in)* `add it` | adds it, says what's useful and where |
| `add the PDF I just downloaded` | finds it in Downloads, asks you to confirm |
| `add this: [link]` | `/draftly add this: https://www.legislation.gov.uk/ukpga/2023/29` |
| `add the new files` | everything in the inbox folder |
| `what do my sources say about [topic]?` | `/draftly what do my sources say about step-in risk?` |
| `read [source] properly and take notes` | chapter by chapter, with pages |
| `show my library` | opens your library page in the browser |
| `check my bibliography` | missing PDFs, format errors, references that can't be verified |
| `stop using [source]` | retires it, warns if a draft cites it |

### Good to know
- **[CITATION NEEDED]** = a source is still missing · **[PINPOINT NEEDED]** = the page is missing. Claude never invents references.
- 🟢 green tag = backed by your library · 🟠 amber tag = still needs a source.
- Unsure? Just describe what you want in your own words.
